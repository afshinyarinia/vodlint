# Code of conduct

VoDLint welcomes contributors with different backgrounds and experience levels.
This policy applies to repository issues, pull requests, reviews and other
project spaces, including interactions where someone represents this project.

Be respectful, constructive and patient. Discuss the behavior of code and the
evidence for a proposal; give people room to learn and correct mistakes. Respect
people's names, identities, privacy and accessibility needs.

Harassment, discrimination, threats, sexualized attention, personal attacks,
deliberate disruption, and publishing another person's private information are
unacceptable. Disagreement is welcome when expressed without abuse.

## Reporting and enforcement

The maintainer, [@afshinyarinia](https://github.com/afshinyarinia), handles conduct
concerns. For a public incident, mention the maintainer on the relevant issue or
pull request. For sensitive incidents, ask the maintainer there for a private
reporting channel without posting personal details. Do not use security
vulnerability reports for conduct complaints. If the concern involves the
maintainer or violates GitHub's rules, use GitHub's **Report abuse** mechanism.

The maintainer may request corrections, issue warnings, remove abusive content,
or restrict participation depending on severity and repetition. Reports should
be handled discreetly; retaliation against someone reporting in good faith is
itself a violation. There is no guaranteed response time.
