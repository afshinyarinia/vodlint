# Security policy

## Supported versions

Security fixes target the latest released VoDLint version, currently 0.2.0.
Older releases may require an upgrade rather than a backported fix.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/afshinyarinia/vodlint/security/advisories/new).
Do not put suspected vulnerabilities, credentials, signed URLs, private media or
keys in public issues. Include the affected version, impact, reproduction steps
and a small sanitized fixture when possible. Share sensitive details only in the
private report. The repository maintainer reviews reports on a best-effort basis;
there is no guaranteed response or disclosure deadline.

The maintainer will coordinate a fix and disclosure with the reporter. Ordinary
correctness problems and feature requests belong in GitHub Issues.
